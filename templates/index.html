What is Top-K?

When you ask a question, the vector store ranks every chunk by semantic similarity. Top-K tells Chroma how many of the highest-ranked chunks to retrieve and feed to the LLM.

  • K = 1: Sends only the #1 top chunk (Fastest, minimal tokens, but risks missing multi-part answers).
  • K = 3: Sends the top 3 chunks (Balanced accuracy and context).
  • K = 5: Sends the top 5 chunks (Comprehensive context, but higher token count & latency).

Phase 3: Retrieval Quality Benchmark

Why Benchmark Retrieval Quality?

Standard vector search can fail on exact keywords or return irrelevant chunks. This benchmark compares 4 advanced retrieval strategies side-by-side:

1. Dense Vector

Standard Bi-Encoder semantic search (MiniLM baseline).

2. Hybrid Search

Combines Dense Vector + BM25 keyword matching with RRF rank fusion.

3. Vector + Reranker

Dense search candidates re-scored using Cross-Encoder attention.

4. Hybrid + Reranker

The gold standard: Fused Hybrid candidates re-ranked by Cross-Encoder.
